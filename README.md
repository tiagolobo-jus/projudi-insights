# PROJUDI Insights

Edição com as respostas e comentários da pesquisa, publicada mediante autorização expressa do responsável. Os dados incorporados são acessíveis publicamente.

Aplicação estática sem dependências de instalação. Publique a raiz desta pasta no GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). Todos os recursos usam caminhos relativos.

Os números são calculados a partir da planilha. Pesquisa voluntária, sem comparação empírica com eproc. Classificação temática exige revisão humana; revisões são salvas no navegador.
